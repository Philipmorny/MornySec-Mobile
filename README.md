# 📱 MornySec-Mobile

> **⚠️ IMPORTANT: For authorized security testing only. Unauthorized access is illegal.**

## 📋 Overview

MornySec-Mobile is an advanced mobile device security assessment framework that discovers phones on your network, exploits vulnerabilities, and provides a full Command & Control (C2) interface.

## 👤 Author

**Philip Morny**

## 🔥 Features

- ✅ **Device Discovery** - Find Android/iOS devices
- ✅ **ADB Exploitation** - Exploit Android Debug Bridge
- ✅ **Command & Control** - Full C2 interface
- ✅ **Screenshot Capture** - Remotely capture screenshots
- ✅ **Contact Extraction** - Extract contacts
- ✅ **SMS Extraction** - Read SMS messages
- ✅ **Location Tracking** - Get GPS coordinates
- ✅ **Camera Access** - Remote camera control
- ✅ **Microphone Access** - Remote audio recording
- ✅ **File Management** - Upload/Download files
